Module 0 · 사전 안내

AI 핵심 원리 & Windows 실행 환경

교육 시작 전, 아래 두 가지 핵심 원리와 사전 체크리스트만 확인하시면 전체 8시간 과정을 훨씬 수월하게 따라가실 수 있습니다.

1. 질문이 구체적일수록 결과물의 수준이 달라집니다

AI(Gemini, Claude 등)에게 포괄적으로 질문하기보다 아래 3가지 요소를 함께 적어주시면 바로 보고에 쓸 수 있는 수준의 결과물이 나옵니다.

  • ① 관점 지정: "15년 경력의 수변전 설비 전문가 / 경영기획 부서장 관점으로"
  • ② 목적·배경: "다음 주 본부장 보고용이며, 투자 우선순위 의사결정이 목적임"
  • ③ 출력 형식: "도입 난이도별 비교표로 정리", "핵심 3줄 요약 후 실행안 제시"
  • 🔒 사내 보안 원칙: 대외비 수치·고객명·고유 설비명은 외부 웹 AI에 직접 입력하지 않고 A사업장, 변압기 #2처럼 익명화하여 입력합니다.

2. Windows 폴더에서 터미널(CLI) 바로 실행하기

복잡한 경로 이동 명령어(cd)를 외우실 필요가 없습니다. 작업할 폴더에서 아래 3단계만으로 즉시 시작됩니다.

1
분석할 업무 파일들이 들어있는 폴더(예: 바탕화면\AI교육)를 엽니다.
2
폴더 상단 경로 주소창을 마우스로 클릭하고 cmd 입력 후 Enter를 누릅니다.
3
열린 검은색 터미널 창에 claude 입력 후 Enter를 누르면 해당 폴더가 즉시 AI와 연결됩니다.

    Module 2 · 2교시 (4시간 · 핵심 과정)

    Claude Code 활용 — 내 PC 폴더에서 직접 실행하는 AI

    웹 채팅창을 넘어 내 컴퓨터의 작업 폴더에 직접 접근하여 파일을 읽고, 보고서를 작성하고, 웹페이지까지 생성합니다.

    💡 CLI(터미널) 방식 vs PC 앱 방식 비교

    교육장 환경에 따라 두 가지 중 하나의 화면을 사용하게 됩니다. 지시하는 방법과 핵심 기능은 동일하므로 아래 두 화면을 전환하며 미리 익혀두시면 좋습니다.

    💻 방식 A. Windows 터미널(CLI)
    • PowerShell 또는 CMD 창에서 claude 입력 후 실행
    • 텍스트 중심 화면으로 가볍고 응답 속도가 빠름
    • 실무 교육에서 가장 표준적으로 활용되는 형태
    🖥️ 방식 B. Claude 데스크톱 앱
    • 좌측에 프로젝트 폴더와 파일 목록이 시각적으로 표시됨
    • 메신저형 대화창과 마우스 클릭으로 직관적 조작 가능
    • 비개발 직군 및 관리자 과정에서 선호되는 형태

      💬 보직장 실무 적용 핵심 체크포인트 (Claude Code)

      Q. 기존 웹 채팅(Claude.ai)과 무엇이 가장 다른가요?

      웹 채팅은 파일을 매번 하나씩 업로드해야 하지만, Claude Code는 내 PC의 업무 폴더 전체를 한 번에 읽고 요약 보고서(.md)나 대시보드(index.html) 파일을 폴더 안에 직접 생성해 줍니다.

      Q. 터미널에 뜨는 영문 로그(● Read, ● Write)는 무엇인가요?

      Claude가 '파일 읽는 중(Read)', '새 문서 저장 중(Write)'이라고 현재 진행 상태를 표시하는 로그입니다. 영어로 입력하실 필요 없이 한국어로 자연스럽게 요청하시면 됩니다.

      Q. 실수 없이 원하는 결과물을 얻는 요령이 있나요?

      한 번에 복잡한 요청을 하기보다 위 실습처럼 ① 폴더 파일 파악 → ② 핵심 요약 보고서 생성 → ③ 대시보드 시각화 순서로 나누어 요청하면 훨씬 정확한 결과를 얻을 수 있습니다.

      Q. 매번 같은 설명을 반복하지 않으려면 어떻게 하나요? (CLAUDE.md)

      작업 폴더 안에 CLAUDE.md라는 텍스트 메모 파일을 만들고 "우리 부서 보고서는 항상 핵심 3줄 요약과 표를 먼저 배치할 것"처럼 작성 기준을 적어두면, 실행할 때마다 자동으로 반영됩니다.

      Module 3 · 3교시 (1시간)

      MCP (Model Context Protocol) — AI와 사내 데이터를 연결하는 표준 규격

      아무리 뛰어난 AI라도 우리 부서의 로컬 폴더, 사내 ERP DB, 내부 규정집은 스스로 열람할 수 없습니다. MCP는 별도의 복잡한 시스템 개발 없이 AI에게 '사내 데이터 조회 통로(도구)'를 안전하게 연결해 주는 공통 규격입니다.

      기존 방식 (MCP 연결 전)

      ❌ 사람이 직접 여러 시스템에서 자료를 찾아 복사·붙여넣기

      • 반복 수작업: 장애이력 폴더에서 PDF 열고, 국가법령 사이트 검색하고, ERP에서 예산 엑셀을 각각 다운로드해야 함
      • 맥락 단절: 자료가 바뀔 때마다 채팅창에 다시 파일을 첨부하고 설명해야 함
      • 근거 부족: AI가 사내 최신 수치를 모르기 때문에 일반적인 답변만 제시함
      MCP 적용 방식 (3교시 실습)

      ✅ 질문 한 줄로 AI가 연결된 폴더·법령·DB를 직접 조회해 종합 보고

      • 실시간 직접 조회: 부서장이 질문하면 Claude가 필요한 MCP 도구를 스스로 골라 최신 원본 데이터를 가져옴
      • 다중 데이터 교차 분석: 폴더 이력 + 최신 법령 + ERP 잔여 예산을 한 번에 묶어 실행 가능한 보고서 작성
      • 사전 승인(Permission) 통제: 데이터에 접근하기 직전 항상 부서장의 승인(1. Yes)을 거치므로 보안 유지

      🔍 MCP는 어떤 구조로 동작하나요? (3대 구성요소와 데이터 흐름)

      실습 환경에서는 작업 폴더의 설정 파일(.mcp.json)에 사용할 데이터 서버를 등록해 두기만 하면, Claude Code가 실행될 때 자동으로 도구를 인식합니다.

      ① AI 호스트 (Host)
      Claude Code (터미널 / 데스크톱 앱)

      부서장의 한국어 업무 요청을 이해하고, 어떤 데이터 서버의 도구를 호출할지 판단한 뒤 최종 분석 결과를 보고합니다.

      ⇄
      MCP 표준 프로토콜
      (요청 & 보안 승인)
      ② MCP 서버 (연결 통로)
      도구(Tool)별 전용 브릿지 프로그램

      허용된 권한 범위 안에서만 작동하는 소형 연결 모듈입니다. (예: filesystem, kepco_law_search, scada_erp_db)

      ⇄
      읽기·조회 실행

        Q. 승인 창이 떴을 때 [1번 Yes]와 [2번 Yes, don't ask again] 중 무엇을 골라야 하나요?

        • 단순 문서·DB 읽기(조회): 2번(세션 동안 자동 허용)을 선택하면 복합 질문(④번 시나리오 등)을 할 때 매번 승인할 필요 없이 빠르게 연속 분석할 수 있습니다.
        • 파일 수정·삭제·외부 전송: 반드시 1번(이번만 허용)으로 건별 확인하거나 의도와 다를 경우 3번(No/Esc)으로 차단하세요.

        Q. 부서원이나 비개발자도 MCP 연결(.mcp.json)을 직접 설정해야 하나요?

        아닙니다. 교육장과 현업에서는 사전 구성된 표준 설정 파일(.mcp.json)을 작업 폴더에 복사해 두는 방식으로 즉시 사용합니다. 부서장은 위 시뮬레이터의 ⚙️ .mcp.json 설정 보기처럼 어떤 폴더와 DB가 연결되어 있는지만 파악하시면 충분합니다.

        Q. 왜 PPT나 엑셀 대신 단일 웹 파일(index.html)로 제작하나요?

        별도 프로그램이나 서버 설치 없이 파일 하나만 메일·메신저로 공유해도 누구나 브라우저(크롬·엣지)에서 더블클릭으로 즉시 열 수 있으며, 임원 회의 중 필터를 바꿔가며 실시간 브리핑이 가능하기 때문입니다.

        Q. 한글이 깨지거나 다음 달 신규 실적을 반영할 때는 어떻게 하나요?

        • 한글 깨짐 발생 시: "UTF-8 인코딩을 적용해 한글 깨짐을 수정해 줘"라고 한 줄만 지시하면 즉시 해결됩니다.
        • 익월 데이터 갱신 시: 폴더에 새 엑셀 파일을 넣고 "신규 파일을 반영해 대시보드 수치를 업데이트해 줘"라고 지시하면 됩니다.

        참고 자료

        교육장 핵심 용어 정리

        강의 중 자주 등장하는 주요 기술 용어를 업무 관점으로 간결하게 정리했습니다.

        프롬프트 (Prompt)

        AI에게 원하는 결과를 얻기 위해 입력하는 지시문입니다. 구체적인 업무 지시서와 같습니다.

        CLI (Command Line Interface)

        마우스 아이콘 대신 터미널 창에 텍스트 명령어를 입력하여 프로그램을 실행하는 방식입니다.

        컨텍스트 (Context) / 토큰

        AI가 한 번에 기억하고 처리하는 작업 맥락의 크기입니다. 대화가 길어지면 /compact로 정리합니다.

        할루시네이션 (Hallucination)

        AI가 확인되지 않은 정보를 사실처럼 작성하는 현상입니다. Deep Research처럼 출처 확인이 중요합니다.

        MCP (Model Context Protocol)

        AI가 로컬 파일, 사내 시스템, 외부 서비스와 안전하게 데이터를 주고받도록 연결하는 표준 규격입니다.

        정적 vs 동적 대시보드

        정적은 고정된 이미지·슬라이드이며, 동적은 필터 선택에 따라 데이터와 차트가 실시간 갱신되는 화면입니다.

        CLAUDE.md (프로젝트 지침서)

        작업 폴더에 넣어두는 부서 전용 업무 수칙 메모입니다. 보고서 양식·용어 기준을 적어두면 AI가 매번 자동으로 준수합니다.

        에이전트 (AI Agent)

        단순 질문 답변을 넘어 스스로 계획을 세우고 파일 열람(Read), 문서 작성(Write), 데이터 조회를 연속 수행하는 AI입니다.
