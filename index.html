Module 0 · 사전 안내

AI 핵심 원리 & Windows 실행 환경

교육 시작 전, 세 가지 핵심 원리만 파악하시면 전체 과정을 훨씬 수월하게 따라가실 수 있습니다.

1. AI는 '지시가 명확할수록 뛰어난 전담 참모'

AI(Gemini, Claude 등)는 방대한 지식을 갖춘 실무 참모와 같습니다. 포괄적인 질문보다 아래 3가지 요소를 함께 전달할 때 보고서 품질이 크게 높아집니다.

  • ① 역할 부여: "15년 경력의 전기설비 전문가 / 경영기획 총괄 관점으로"
  • ② 목적·배경: "다음 주 임원 보고용이며, 핵심 의사결정이 목적임"
  • ③ 출력 형식: "비교표로 정리", "핵심 3가지 요약 후 실행안 제시"

2. Windows에서 명령 프롬프트(터미널) 실행하기

교육 환경에 따라 CLI(명령어 기반 화면)를 사용할 수 있습니다. 아래 3단계만으로 바로 실행됩니다.

1
작업할 폴더(예: 바탕화면\AI교육)를 엽니다.
2
폴더 상단 주소창을 클릭하고 cmd 입력 후 Enter를 누릅니다.
3
열린 창에 claude 입력 후 Enter를 누르면 즉시 시작됩니다.
💡 더 알면 좋은 실무 팁 (사전 준비)
  • 사내 보안 기본 수칙: 대외비 수치, 고객명, 개인정보는 외부 AI에 직접 입력하지 않고 A사업장, 설비 #1처럼 익명화하여 질문하는 것이 안전합니다.
  • 경로 이동 없이 실행하기: 명령 프롬프트에서 복잡한 폴더 이동 명령어(cd)를 외우실 필요 없이, 작업할 폴더를 연 상태에서 주소창에 cmd만 입력하시면 바로 해당 위치에서 시작됩니다.

    💬 처음 사용할 때 자주 궁금해하는 점 (Deep Research)

    Q. '리서치 계획'은 왜 중간에 확인하나요?

    AI가 3~5분 동안 수십 개 사이트를 조사하기 전에 조사 방향과 목차가 우리 부서 의도와 맞는지 먼저 확인하기 위함입니다. 방향이 다르면 '계획 수정'으로 바로잡을 수 있습니다.

    Q. 보고서의 출처는 신뢰할 수 있나요?

    보고서 본문마다 [1], [2] 형태의 출처 링크가 함께 생성됩니다. 중요 수치는 해당 링크를 클릭해 원문(공공기관 공고, 기사, 논문 등)을 바로 교차 검증할 수 있습니다.

    Q. 완성된 보고서는 어떻게 활용하나요?

    우측 상단의 'Docs로 내보내기'를 누르면 Google 문서로 즉시 변환되어 팀원에게 공유하거나 임원 보고서 초안으로 바로 다듬을 수 있습니다.

    Q. 사내 대외비 자료를 질문에 넣어도 되나요?

    Deep Research는 외부 웹 검색 기반 기능입니다. 질문에 사내 기밀 수치나 개인정보는 제외하고, 공개된 산업 동향·법령·벤치마킹 중심으로 요청하시는 것이 안전합니다.

    💡 더 알면 좋은 실무 팁 (Deep Research)
    • 백그라운드 실행: 연구 시작을 누른 뒤에는 창을 닫거나 다른 업무를 보셔도 리서치가 계속 진행되며, 완료 후 좌측 최근 항목에서 다시 열어보실 수 있습니다.
    • 이어서 재가공하기: 보고서가 완성된 뒤 하단 입력창에 "위 내용을 임원 보고용 1페이지 핵심 요약표로 다시 정리해 줘"처럼 후속 지시를 이어갈 수 있습니다.

    Claude Code 활용 — 내 PC 폴더에서 직접 실행하는 AI

    웹 채팅창을 넘어 내 컴퓨터의 작업 폴더에 직접 접근하여 파일을 읽고, 보고서를 작성하고, 웹페이지까지 생성합니다.

    💡 CLI(터미널) 방식 vs PC 앱 방식 비교

    교육장 환경에 따라 두 가지 중 하나의 화면을 사용하게 됩니다. 지시하는 방법과 핵심 기능은 동일하므로 아래 두 화면을 전환하며 미리 익혀두시면 좋습니다.

    💻 방식 A. Windows 터미널(CLI)
    • PowerShell 또는 CMD 창에서 claude 입력 후 실행
    • 텍스트 중심 화면으로 가볍고 응답 속도가 빠름
    • 실무 교육에서 가장 표준적으로 활용되는 형태
    🖥️ 방식 B. Claude 데스크톱 앱
    • 좌측에 프로젝트 폴더와 파일 목록이 시각적으로 표시됨
    • 메신저형 대화창과 마우스 클릭으로 직관적 조작 가능
    • 비개발 직군 및 관리자 과정에서 선호되는 형태

      💬 처음 사용할 때 자주 궁금해하는 점 (Claude Code)

      Q. 이름에 'Code'가 있는데 코딩을 몰라도 되나요?

      네, 직접 코드를 작성하실 필요가 없습니다. 한국어로 업무를 지시하면 Claude Code가 파일 분석, 문서 정리, 웹 대시보드 코드 작성을 대신 처리합니다.

      Q. 웹 채팅(Claude.ai)과 무엇이 다른가요?

      웹 채팅은 매번 파일을 업로드하고 결과를 복사해야 하지만, Claude Code는 내 PC 폴더 안에서 여러 파일을 직접 읽고 결과 파일까지 저장해 줍니다.

      Q. 내 PC의 다른 중요한 파일까지 건드리진 않나요?

      Claude Code는 실행한 현재 작업 폴더 내부만 기준으로 동작하며, 파일을 새로 쓰거나 수정·실행할 때는 사전에 사용자에게 승인을 요청합니다.

      Q. 원하는 결과가 안 나오면 어떻게 하나요?

      "표가 너무 복잡하니 핵심 3개만 남겨줘"처럼 자연스럽게 추가 수정 지시를 하시면 기존 파일을 유지한 채 필요한 부분만 고쳐줍니다.

      💡 더 알면 좋은 실무 팁 (Claude Code)
      • 단계별 지시가 정확도를 높입니다: 한 번에 모든 작업을 시키기보다 ① 파일 파악 → ② 요약 보고서 생성 → ③ 대시보드 제작 순으로 나누어 지시하면 실수가 훨씬 줄어듭니다.
      • 수정 취소 및 복구: 결과가 의도와 다를 때는 "방금 수정한 부분 이전 상태로 되돌려 줘"라고 지시하거나, 승인 단계에서 거절(No)하시면 변경 없이 안전하게 유지됩니다.
      Module 3 · 3교시 (1시간)

      MCP (Model Context Protocol) — AI 데이터 연결 표준

      AI가 내 PC의 문서, 사내 데이터베이스, 외부 웹 도구와 안전하게 연결될 수 있도록 해주는 표준 연결 규격(USB-C 역할)입니다.

      Claude Code 분석 및 작업 수행
      🔌 MCP 표준 연결
      (만능 어댑터)
      📂 내 PC 폴더 / Excel · CSV
      🌐 실시간 웹 검색 · API
      📊 사내 DB / 노션 / 드라이브
      Claude Code — MCP 도구 실행 승인 화면 체험
      실제 화면 체험
      보안 원칙상 AI는 외부 데이터에 접근할 때 반드시 사용자의 실행 승인을 요청합니다. 실습 중 아래 승인 창이 뜨면 당황하지 마시고 [1. Yes (허용)]을 선택하시면 됩니다.
      1. 자료 조회 요청 → 2. 실행 승인(Yes) → 3. 데이터 분석 완료

      💬 처음 사용할 때 자주 궁금해하는 점 (MCP)

      Q. MCP가 도입되기 전에는 어떻게 했나요?

      과거에는 AI 서비스마다 사내 DB, 엑셀, 노션 등을 연결하는 맞춤 프로그램을 매번 따로 개발해야 했습니다. MCP는 이를 USB-C처럼 하나의 표준 규격으로 통일했습니다.

      Q. 실제로 어떤 업무 도구들을 연결할 수 있나요?

      내 PC 폴더(파일 시스템), Excel/CSV 데이터, Google Drive, Notion, Slack, 사내 데이터베이스, 실시간 웹 브라우저 등 다양한 도구를 플러그처럼 연결할 수 있습니다.

      Q. 연결하면 AI가 모든 사내 데이터를 다 보게 되나요?

      아닙니다. 사용자가 허용한 특정 폴더나 도구에만 접근 가능하며, 실제로 데이터를 조회하거나 변경할 때마다 위 체험처럼 실행 승인 여부를 물어보도록 제어할 수 있습니다.

      Q. 부서장 입장에서 MCP를 알면 무엇이 좋나요?

      우리 팀의 점검 일지나 실적 파일이 있는 폴더에 MCP만 연결해 두면, AI가 매번 파일을 붙여넣지 않아도 최신 데이터를 직접 읽고 현황을 보고하게 만들 수 있습니다.

      💡 더 알면 좋은 실무 팁 (MCP)
      • 팀 규정·매뉴얼 자동 응답: 팀 내 최신 안전 규정집이나 업무 매뉴얼 폴더를 MCP로 연결해 두면, 구성원 문의 시 항상 최신 문서 기준으로 일관된 답변을 얻을 수 있습니다.
      • 최소 권한 원칙 유지: 읽기(조회) 작업은 세션 허용을 쓰더라도, 파일 삭제·덮어쓰기·외부 전송 도구는 매번 확인(Yes)하도록 두는 것이 실무 보안상 안전합니다.
      Module 4 · 4교시 최종 과제 (1시간)

      동적 대시보드 제작 — 최종 과제 완성 예시

      고정된 이미지 형태의 보고서가 아니라, 기간과 구역/팀 필터를 선택할 때마다 수치와 그래프가 즉시 반응하는 웹 대시보드입니다. 아래 완성본의 드롭다운 메뉴를 직접 변경해 보며 최종 결과물의 형태를 확인해 보세요.

      부서장용 실시간 현황 대시보드 (과제 완성 예시)
      ● LIVE 동작 중

      🏆 과제 제출 시 Claude Code에 입력하는 제작 요청 프롬프트

      마지막 과제 시간에 아래 문구를 복사해 입력하시면, 데이터가 반영된 동적 대시보드를 손쉽게 완성하실 수 있습니다.

      💬 최종 과제 제출 전 알아두면 좋은 점

      Q. 완성된 대시보드는 어떤 파일로 나오나요?

      보통 index.html 웹 파일 형태로 생성됩니다. 별도 프로그램 설치 없이 크롬이나 엣지 브라우저로 열면 바로 화면이 나타납니다.

      Q. 다음 달 새 데이터가 생기면 어떻게 업데이트하나요?

      같은 폴더에 새 엑셀/CSV 파일을 넣고 Claude Code에게 "새로 넣은 12월 데이터를 반영해서 대시보드를 업데이트해 줘"라고 지시하면 즉시 갱신됩니다.

      💡 더 알면 좋은 실무 팁 (동적 대시보드 과제)
      • 파일 하나로 간편한 공유: 별도 서버 없이 동작하는 단일 index.html 형태로 만들어 달라고 요청하면, 메일이나 메신저로 파일을 전달해 누구나 브라우저에서 바로 열어볼 수 있습니다.
      • 시각적 완성도 높이기: 기본 대시보드가 완성된 뒤 "상단 컬러를 네이비 톤으로 맞추고, 인쇄용 PDF 저장 버튼도 추가해 줘"처럼 마무리 요청을 하면 보고용 완성도가 크게 올라갑니다.
      참고 자료

      교육장 핵심 용어 정리

      강의 중 자주 등장하는 주요 기술 용어를 업무 관점으로 간결하게 정리했습니다.

      프롬프트 (Prompt)

      AI에게 원하는 결과를 얻기 위해 입력하는 지시문입니다. 구체적인 업무 지시서와 같습니다.

      CLI (Command Line Interface)

      마우스 아이콘 대신 터미널 창에 텍스트 명령어를 입력하여 프로그램을 실행하는 방식입니다.

      컨텍스트 (Context) / 토큰

      AI가 한 번에 기억하고 처리하는 작업 맥락의 크기입니다. 대화가 길어지면 /compact로 정리합니다.

      할루시네이션 (Hallucination)

      AI가 확인되지 않은 정보를 사실처럼 작성하는 현상입니다. Deep Research처럼 출처 확인이 중요합니다.

      MCP (Model Context Protocol)

      AI가 로컬 파일, 사내 시스템, 외부 서비스와 안전하게 데이터를 주고받도록 연결하는 표준 규격입니다.

      정적 vs 동적 대시보드

      정적은 고정된 이미지·슬라이드이며, 동적은 필터 선택에 따라 데이터와 차트가 실시간 갱신되는 화면입니다.
